# Guide de déploiement (à compléter avant la livraison finale)

Livrable demandé par M. Uribe Lobello : un guide pas à pas, compréhensible par une personne qui n'est pas informaticienne.

## Plan prévu

1. Ce qu'il faut avant de commencer (installer Node.js, version 20.19 ou plus récente)
2. Récupérer le projet depuis EtuLab (bouton « Code » puis « Télécharger le ZIP »)
3. Ouvrir un terminal dans le dossier du projet
4. `npm install` (une seule fois)
5. `npm run build` : crée le dossier `dist/`
6. Copier le contenu de `dist/` sur le serveur web (ou GitHub Pages, ou l'hébergement de l'IUT)
7. Vérifier : ouvrir l'adresse dans Firefox et charger `exemples/demo.asm`
8. Problèmes fréquents et solutions

Chaque étape sera illustrée par une capture d'écran.
